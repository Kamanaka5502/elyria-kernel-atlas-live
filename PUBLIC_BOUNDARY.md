# Public Boundary

Elyria Kernel Atlas Live is a public visual atlas for Elyria Systems category language.

It shows kernel families, consequence corridors, receipt concepts, replay posture, and public-safe summaries.

## Shown here

- Visual kernel categories
- Public-safe corridor descriptions
- Read-only Flask pages
- Read-only JSON endpoints
- Reviewer-friendly setup instructions

## Not shown here

- Production runtime logic
- Internal evaluators
- Internal thresholds
- Customer-specific rules
- Deployment adapters
- Production infrastructure

## Intended use

Use this repository as a public sandbox, visual demo, and portfolio surface.

It is not the implementation layer.

## Boundary statement

Public atlas is visible. Runtime implementation remains separate.
