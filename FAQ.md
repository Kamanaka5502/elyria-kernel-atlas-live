# FAQ

## What is this repository?

A public visual atlas for Elyria Systems kernel categories and corridor language.

## Is this a live production system?

No. It is a public-facing atlas and sandbox surface.

## Can reviewers run it locally?

Yes.

```bash
python app.py
```

Then open:

```text
http://127.0.0.1:5000
```

## What endpoints exist?

```text
/api/kernels
/api/install-proof
```

## Are the endpoints read-only?

Yes. They return public summaries.

## What should reviewers look for?

- category clarity
- kernel coverage
- public boundary clarity
- local reproducibility
- simple API inspection

## Who prepared it?

Samantha Revita and Terry Snyder / Elyria Systems.
