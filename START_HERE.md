# Start Here

Elyria Kernel Atlas Live is the public entry point for the Elyria Systems kernel map.

It gives reviewers one place to see the categories, corridors, and public language of the system.

## What to open first

1. `README.md`
2. `PUBLIC_BOUNDARY.md`
3. `VERIFY.md`
4. The local app at `http://127.0.0.1:5000`

## What this project is

A public atlas.

A live visual surface.

A sandbox for orientation.

## What this project is not

It is not the full implementation.

It is not a customer deployment.

It is not a certification package.

## Run

```bash
python app.py
```

Then open:

```text
http://127.0.0.1:5000
```
